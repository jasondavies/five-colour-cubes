# Unsuccessful degree-only shortcut

This folder records discovery work, not a proof input.

The proposed shortcut was to find an opposite target on which every
directed corner has at least three source neighbours, in a pool of
five capped opposite and nine capped adjacent cubes. That condition
is not always available. The integer-feasibility searches found valid
source counts whose low-degree edges meet every four-cycle, including
examples with at most one doubled opposite variety.

The completed theorem instead uses the virtual-triple replacement
lemma and the existing small grid constructions; see
`../root/five-opposites-nine-adjacent.md`. The feasibility output here
is retained only to avoid rediscovering this failed sufficient-condition
approach. It is not used to infer the theorem or its completeness.
